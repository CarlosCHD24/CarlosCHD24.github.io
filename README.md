# Visor de empleo público

Sitio web estático para consultar el maestro consolidado de oportunidades de empleo público en Sevilla y su provincia.

La aplicación se encuentra en `frontend/` y se publica mediante GitHub Pages en
`https://carloschd24.github.io/`.

El origen verificable de las cifras y reglas de presentación es
`context-in-text/empleo_publico_visor.md`.
